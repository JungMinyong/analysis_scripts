# Isolated dwarf parameter export

Start with isolated_run_guide.md and parameter_choices.md. The run-specific input.enzo files are under runs/; root-level templates include historical configurations. Files are copied verbatim from /home/wispedia/AA/isolated. Absolute paths in the documents may need adapting on another machine. Restart parameter files require their matching full checkpoint; startup .enzo files also require the cooling/yield/radiation tables described in the guide. Those tables, binaries and snapshots are not included.

EXPORT_SHA256SUMS lists the original file checksums. No Git commit or push is performed.
